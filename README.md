# Лабораторна робота №3 — Варіант 1 «Морський бій»

**Android-застосунок на Java + окремий Python/FastAPI-сервіс для інтелектуального суперника.** Грають людина й комп'ютер. Вибір ходів суперника **не використовує `random`**: він ґрунтується на переборі допустимих розміщень кораблів і карті ймовірностей.

## Вимоги до середовища

- Android Studio із Android SDK 35 та JDK 17. Gradle Wrapper 8.9 уже включено.
- Python 3.10+.
- Android Emulator (для фізичного смартфона потрібно змінити адресу API у `AiClient.java` на локальну IP-адресу комп'ютера; мобільний пристрій і сервер мають бути в одній мережі).

## Запуск Python AI

Із кореня репозиторію:

```bash
cd python-ai
python3 -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
python -m uvicorn main:app --host 0.0.0.0 --port 8000
```

Перевірка: `http://127.0.0.1:8000/health` повертає `{"status":"ok"}`. Документація API: `http://127.0.0.1:8000/docs`.

## Запуск Android

1. Запустіть Python-сервіс.
2. В Android Studio відкрийте папку **`android`** (`File → Open`).
3. Дочекайтеся **Gradle Sync** (SDK 35 може знадобитися завантажити).
4. Створіть або виберіть емулятор Android API 24+, натисніть **Run**.
5. Android Emulator звертається до Python-сервера на хості через `http://10.0.2.2:8000`.
6. Натисніть на клітинку верхнього поля суперника, щоб зробити постріл. Нижнє поле — ваші кораблі. Кнопка «Нова гра» починає нову партію.
7. Якщо Python-сервіс недоступний, доступна кнопка «Повторити хід комп'ютера» після відновлення з'єднання.

**Примітка:** для локальної лабораторної демонстрації використовується HTTP і `usesCleartextTraffic=true`. Для продакшну необхідні HTTPS, безпечна конфігурація мережі й підвищений targetSdk.

## Правила реалізації

- Поле **10×10**, флоти: кораблі довжини **5, 4, 3, 3, 2** (навчальне спрощення; не класичний склад флоту 4/3/2/1).
- Кораблі не торкаються один одного навіть по діагоналі.
- Початкове розташування кораблів задане валідним шаблоном та змінюється **детермінованими геометричними перетвореннями** між партіями.
- Постріли по черзі (по одному пострілу на хід незалежно від влучання).
- `M` — промах, `H` — пошкоджена частина, `S` — потоплена частина, `.` — невідома клітинка.
- Корабель потоплено, якщо пошкоджені всі його клітинки. Перемагає гравець, який потопив увесь флот суперника.

## Як працює ШІ

1. Android надсилає **лише історію пострілів комп'ютера**, а не місця ваших кораблів.
2. Python переглядає кожне допустиме горизонтальне й вертикальне розміщення кораблів, що залишилися.
3. Будує теплову карту клітинок (скільки допустимих розміщень включають клітинку).
4. Після влучання надає пріоритет розміщенням, які узгоджуються з уже знайденими пошкодженими секціями.
5. Для рівних оцінок використовує сталий порядок (центр → рядок → стовпець). **Жодної випадковості чи платного API.**

Це **алгоритмічний ігровий ШІ** (probability search / hunt-target), а не нейромережа чи LLM. Якщо викладач вимагає саме ML/нейромережу, реалізацію потрібно погодити окремо.

### API

`POST /api/ai/move`:

```json
{"board": ["..........", "..........", "..........", "..........", "....H.....", "..........", "..........", "..........", "..........", ".........."], "remaining": [5,4,3,3,2]}
```

Відповідь, наприклад: `{"row": 3, "col": 4, "strategy": "deterministic-probability"}`. Обидва індекси від нуля.
